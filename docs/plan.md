# Schedule

The schedule screen provides a view of the measurements carried out and to be carried out.

[![Screenshot](images/cal.png)](images/cal.png)

The left part of the screen contains past and future measurements. By clicking on a column,
you are returned to the [list of measurements](controls.md#list) planned for the corresponding month.


The right side contains the measurements scheduled for this month. It is possible to change the current month and select
a [measurement](controls.md#show) in the calendar.
